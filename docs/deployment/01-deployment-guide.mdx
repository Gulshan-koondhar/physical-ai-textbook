# Deployment Guide for Physical AI & Humanoid Robotics

## Introduction

Deploying physical AI systems and humanoid robots in production environments requires careful planning, robust infrastructure, and comprehensive monitoring. Unlike traditional software applications, humanoid robots operate in dynamic physical environments and require real-time performance, safety considerations, and continuous operation. This guide covers the essential aspects of deploying AI-powered humanoid robots from development to production.

The deployment of humanoid robots involves multiple layers: hardware deployment, software deployment, model deployment, and operational deployment. Each layer has its own challenges and requirements that must be addressed for successful deployment.

## Pre-Deployment Planning

### Environment Assessment

Before deploying humanoid robots, conduct a thorough environment assessment:

#### Physical Environment
- **Space Requirements**: Measure available space and plan robot navigation paths
- **Obstacle Mapping**: Identify static and dynamic obstacles
- **Surface Conditions**: Assess floor types, gradients, and slipperiness
- **Lighting Conditions**: Evaluate ambient lighting for vision systems
- **Acoustic Environment**: Assess noise levels for audio processing

#### Network Infrastructure
- **WiFi Coverage**: Ensure comprehensive coverage with minimal dead zones
- **Bandwidth Requirements**: Calculate bandwidth for video streaming, data transmission
- **Latency Requirements**: Ensure low-latency communication for real-time control
- **Security**: Implement secure network protocols and authentication

#### Power Infrastructure
- **Power Availability**: Ensure sufficient outlets and power capacity
- **Backup Power**: Plan for uninterruptible power supplies (UPS)
- **Power Consumption**: Calculate robot power requirements and duty cycles

### Safety Assessment

#### Risk Analysis
- **Human Interaction**: Assess risks during human-robot interaction
- **Emergency Procedures**: Plan for robot malfunctions and emergencies
- **Physical Barriers**: Consider safety barriers and restricted zones
- **Monitoring Systems**: Implement surveillance and alert systems

#### Regulatory Compliance
- **Safety Standards**: Ensure compliance with ISO 13482 (service robots) or other applicable standards
- **Electrical Safety**: Meet electrical safety requirements (IEC, UL standards)
- **EMC Compliance**: Ensure electromagnetic compatibility
- **Local Regulations**: Comply with local robotics regulations

## Hardware Deployment

### Robot Assembly and Integration

#### Pre-Assembly Checks
1. **Component Verification**: Verify all components match specifications
2. **Compatibility Testing**: Test component compatibility before assembly
3. **Firmware Verification**: Ensure all firmware is up-to-date
4. **Documentation Review**: Review assembly procedures and safety guidelines

#### Assembly Process
1. **Mechanical Assembly**: Follow manufacturer's assembly procedures
2. **Electrical Connections**: Verify all connections are secure and correct
3. **Cable Management**: Route cables to prevent interference and damage
4. **Initial Power-On**: Conduct initial power-on tests with safety measures

#### Calibration Procedures
1. **Joint Calibration**: Calibrate all joint encoders and limits
2. **Sensor Calibration**: Calibrate cameras, IMUs, and other sensors
3. **Kinematic Calibration**: Verify forward and inverse kinematics
4. **Performance Testing**: Test torque, speed, and accuracy specifications

```bash
# Power monitoring and management script
#!/bin/bash

# Monitor battery levels
while true; do
    battery_level=$(cat /sys/class/power_supply/BAT0/capacity)

    if [ $battery_level -lt 20 ]; then
        echo "Low battery warning: $battery_level%"
        # Send alert to monitoring system
        curl -X POST http://monitoring/api/alerts \
             -H "Content-Type: application/json" \
             -d "{\"type\":\"battery\",\"level\":$battery_level,\"robot\":\"humanoid-01\"}"

        if [ $battery_level -lt 10 ]; then
            echo "Critical battery level, initiating safe shutdown"
            # Execute safe shutdown procedure
            ssh robot@192.168.1.100 "sudo systemctl start robot-safe-shutdown"
        fi
    fi

    sleep 60  # Check every minute
done
```

### MLflow for Model Management

#### Model Registry Setup
```python
# mlflow_deployment.py
import mlflow
import mlflow.pytorch
import torch
from mlflow.tracking import MlflowClient
import os

class ModelDeploymentManager:
    def __init__(self, tracking_uri="http://mlflow-server:5000"):
        self.client = MlflowClient(tracking_uri=tracking_uri)
        mlflow.set_tracking_uri(tracking_uri)

    def register_model(self, model, model_name, artifacts=None):
        """Register model in MLflow registry"""
        with mlflow.start_run():
            # Log model
            mlflow.pytorch.log_model(
                pytorch_model=model,
                artifact_path="model",
                conda_env="./environment.yml",
                registered_model_name=model_name
            )

            # Log artifacts if provided
            if artifacts:
                for name, path in artifacts.items():
                    mlflow.log_artifact(path, artifact_path=name)

            run_id = mlflow.active_run().info.run_id
            return run_id

    def promote_model(self, model_name, version, stage="Production"):
        """Promote model to production stage"""
        self.client.transition_model_version_stage(
            name=model_name,
            version=version,
            stage=stage
        )

    def get_production_model(self, model_name):
        """Get production model from registry"""
        model_uri = f"models:/{model_name}/production"
        model = mlflow.pytorch.load_model(model_uri)
        return model

    def deploy_model_to_robot(self, model_name, robot_ip, robot_port=8080):
        """Deploy model to robot via REST API"""
        import requests
        import json

        # Get model from registry
        model = self.get_production_model(model_name)

        # Convert model to bytes for transmission
        import io
        buffer = io.BytesIO()
        torch.save(model.state_dict(), buffer)
        model_bytes = buffer.getvalue()

        # Deploy to robot
        url = f"http://{robot_ip}:{robot_port}/api/models/deploy"
        response = requests.post(
            url,
            files={'model': model_bytes},
            data={'model_name': model_name}
        )

        return response.json()

def deploy_models():
    """Deploy all required models to robot"""
    manager = ModelDeploymentManager()

    # Deploy vision model
    vision_model = torch.load("models/vision_model.pt")
    vision_run_id = manager.register_model(
        vision_model,
        "humanoid-vision-model",
        {"config": "configs/vision_config.json"}
    )

    # Promote to production
    manager.promote_model("humanoid-vision-model", "1", "Production")

    # Deploy language model
    language_model = torch.load("models/language_model.pt")
    language_run_id = manager.register_model(
        language_model,
        "humanoid-language-model",
        {"tokenizer": "models/tokenizer.json"}
    )

    # Promote to production
    manager.promote_model("humanoid-language-model", "1", "Production")

    print("Models deployed and promoted to production")

if __name__ == "__main__":
    deploy_models()
```

#### Custom Robot Metrics Exporter
```python
# robot_metrics_exporter.py
from prometheus_client import start_http_server, Gauge, Counter, Histogram
import rospy
from std_msgs.msg import String
import json
import time

class RobotMetricsExporter:
    def __init__(self, port=8080):
        # Define metrics
        self.battery_level = Gauge('robot_battery_percentage', 'Battery level percentage', ['robot'])
        self.cpu_usage = Gauge('robot_cpu_usage_percent', 'CPU usage percentage', ['robot'])
        self.memory_usage = Gauge('robot_memory_usage_percent', 'Memory usage percentage', ['robot'])
        self.vision_errors = Counter('robot_vision_errors_total', 'Total vision errors', ['robot'])
        self.inference_time = Histogram('robot_inference_seconds', 'Inference time in seconds', ['robot', 'model'])

        # Robot state
        self.robot_status = Gauge('robot_operational_status', 'Robot operational status', ['robot'])
        self.active_tasks = Gauge('robot_active_tasks', 'Number of active tasks', ['robot'])

        # Start HTTP server
        start_http_server(port)
        print(f"Metrics exporter started on port {port}")

    def update_battery(self, robot_name, battery_percentage):
        self.battery_level.labels(robot=robot_name).set(battery_percentage)

    def update_cpu_usage(self, robot_name, cpu_percentage):
        self.cpu_usage.labels(robot=robot_name).set(cpu_percentage)

    def update_memory_usage(self, robot_name, memory_percentage):
        self.memory_usage.labels(robot=robot_name).set(memory_percentage)

    def increment_vision_errors(self, robot_name):
        self.vision_errors.labels(robot=robot_name).inc()

    def observe_inference_time(self, robot_name, model_name, time_seconds):
        self.inference_time.labels(robot=robot_name, model=model_name).observe(time_seconds)

    def update_robot_status(self, robot_name, operational):
        self.robot_status.labels(robot=robot_name).set(1 if operational else 0)

    def update_active_tasks(self, robot_name, task_count):
        self.active_tasks.labels(robot=robot_name).set(task_count)

class RobotMetricsListener:
    def __init__(self):
        self.exporter = RobotMetricsExporter()
        self.robot_name = rospy.get_param('~robot_name', 'unknown_robot')

        # Subscribe to robot status topics
```

```python
class RobotAuth:
    @staticmethod
    def generate_token(robot_id, permissions=None):
        """Generate JWT token for robot authentication"""
        payload = {
            'robot_id': robot_id,
            'permissions': permissions or [],
            'exp': datetime.utcnow() + timedelta(hours=24),
            'iat': datetime.utcnow()
        }

        token = jwt.encode(payload, app.config['SECRET_KEY'], algorithm='HS256')
        return token

    @staticmethod
    def verify_token(token):
        """Verify JWT token"""
        try:
            # Check if token is blacklisted
            if redis_client.exists(f"blacklist:{token}"):
                return None

            payload = jwt.decode(token, app.config['SECRET_KEY'], algorithms=['HS256'])
            return payload
        except jwt.ExpiredSignatureError:
            return None
        except jwt.InvalidTokenError:
            return None

    @staticmethod
    def require_auth(permissions=None):
        """Decorator for requiring authentication"""
        def decorator(f):
            @wraps(f)
            def decorated_function(*args, **kwargs):
                token = None

                if 'Authorization' in request.headers:
                    auth_header = request.headers['Authorization']
                    try:
                        token = auth_header.split(" ")[1]  # Bearer <token>
                    except IndexError:
                        return jsonify({'message': 'Invalid token format'}), 401

                if not token:
                    return jsonify({'message': 'Token is missing'}), 401

                payload = RobotAuth.verify_token(token)
                if not payload:
                    return jsonify({'message': 'Token is invalid'}), 401

                # Check permissions if required
                if permissions:
                    user_permissions = set(payload.get('permissions', []))
                    required_permissions = set(permissions)

                return f(*args, **kwargs)
            return decorated_function
        return decorator
```

#### Robot Resource Monitor
```python
# resource_monitor.py
import psutil
import GPUtil
import rospy
from std_msgs.msg import String
import json
import time

class RobotResourceMonitor:
    def __init__(self):
        rospy.init_node('resource_monitor')
        self.status_pub = rospy.Publisher('/system_metrics', String, queue_size=10)

        # Resource thresholds
        self.cpu_threshold = 80  # %
        self.memory_threshold = 85  # %
        self.gpu_threshold = 85  # %

        # Performance metrics
        self.metrics_history = {
            'cpu': [],
            'memory': [],
            'gpu': [],
            'timestamps': []
        }

    def get_system_metrics(self):
        """Get current system resource usage"""
        metrics = {
            'timestamp': rospy.Time.now().to_sec(),
            'cpu_percent': psutil.cpu_percent(interval=1),
            'memory_percent': psutil.virtual_memory().percent,
            'disk_percent': psutil.disk_usage('/').percent,
            'network_io': psutil.net_io_counters()._asdict(),
            'process_count': len(psutil.pids())
        }

        # GPU metrics if available
        gpus = GPUtil.getGPUs()
        if gpus:
            gpu = gpus[0]  # Assuming single GPU
            metrics.update({
                'gpu_load': gpu.load * 100,
                'gpu_memory_used': gpu.memoryUsed,
                'gpu_memory_total': gpu.memoryTotal,
                'gpu_memory_percent': gpu.memoryUtil * 100,
                'gpu_temperature': gpu.temperature
            })

        # Add to history
        self.metrics_history['cpu'].append(metrics['cpu_percent'])
        self.metrics_history['memory'].append(metrics['memory_percent'])
        if 'gpu_load' in metrics:
            self.metrics_history['gpu'].append(metrics['gpu_load'])
        self.metrics_history['timestamps'].append(metrics['timestamp'])

        # Keep only recent history
        max_history = 100
        for key in self.metrics_history:
            if len(self.metrics_history[key]) > max_history:
                self.metrics_history[key] = self.metrics_history[key][-max_history:]

        return metrics

    def check_resource_alerts(self, metrics):
        """Check for resource usage alerts"""
        alerts = []

        if metrics['cpu_percent'] > self.cpu_threshold:
            alerts.append({
                'type': 'high_cpu',
                'severity': 'warning',
                'message': f"CPU usage high: {metrics['cpu_percent']:.1f}%"
            })

        if metrics['memory_percent'] > self.memory_threshold:
            alerts.append({
                'type': 'high_memory',
                'severity': 'warning',
                'message': f"Memory usage high: {metrics['memory_percent']:.1f}%"
            })

        if 'gpu_load' in metrics and metrics['gpu_load'] > self.gpu_threshold:
            alerts.append({
                'type': 'high_gpu',
                'severity': 'warning',
                'message': f"GPU usage high: {metrics['gpu_load']:.1f}%"
            })

        return alerts

    def run(self):
        """Main monitoring loop"""
        rate = rospy.Rate(1)  # 1 Hz monitoring

        while not rospy.is_shutdown():
            try:
                # Get current metrics
                metrics = self.get_system_metrics()

                # Check for alerts
                alerts = self.check_resource_alerts(metrics)

                # Publish metrics
                metrics_msg = String()
                metrics_msg.data = json.dumps({
                    'metrics': metrics,
                    'alerts': alerts,
                    'history': {
                        'cpu_avg': sum(self.metrics_history['cpu'][-10:]) / len(self.metrics_history['cpu'][-10:]),
                        'memory_avg': sum(self.metrics_history['memory'][-10:]) / len(self.metrics_history['memory'][-10:]),
                        'gpu_avg': sum(self.metrics_history['gpu'][-10:]) / max(len(self.metrics_history['gpu'][-10:]), 1) if self.metrics_history['gpu'] else 0
                    }
                })
                self.status_pub.publish(metrics_msg)

                # Log alerts
                if alerts:
                    for alert in alerts:
                        rospy.logwarn(f"Resource Alert: {alert['message']}")

            except Exception as e:
                rospy.logerr(f"Resource monitoring error: {e}")

            rate.sleep()

def main():
    monitor = RobotResourceMonitor()
    try:
        monitor.run()
    except rospy.ROSInterruptException:
        rospy.loginfo("Resource monitor interrupted")
    except KeyboardInterrupt:
        rospy.loginfo("Resource monitor stopped")

if __name__ == "__main__":
    main()
```

## Rollback Procedures

### Safe Rollback Strategy

#### Robot Rollback Script
```bash
#!/bin/bash
# robot_rollback.sh - Safe rollback script for robot deployments

set -e  # Exit on error

ROBOT_NAME=$(hostname)
BACKUP_DIR="/backup/deployments"
CURRENT_DEPLOYMENT="/workspace/current"
PREVIOUS_DEPLOYMENT="/workspace/previous"

log() {
    echo "[$(date '+%Y-%m-%d %H:%M:%S')] $1" | tee -a /var/log/robot_rollback.log
}

# Function to backup current deployment
backup_current() {
    log "Creating backup of current deployment..."

    if [ -d "$CURRENT_DEPLOYMENT" ]; then
        TIMESTAMP=$(date +%Y%m%d_%H%M%S)
        BACKUP_PATH="$BACKUP_DIR/backup_${TIMESTAMP}"
        mkdir -p "$BACKUP_PATH"

        cp -r "$CURRENT_DEPLOYMENT"/* "$BACKUP_PATH/" 2>/dev/null || true

        # Also backup Docker images
        docker images --format "table {{.Repository}}:{{.Tag}}" | grep robot > "$BACKUP_PATH/docker_images.txt"

        log "Backup created at $BACKUP_PATH"
    else
        log "No current deployment to backup"
    fi
}

# Function to rollback to previous version
rollback() {
    log "Starting rollback process..."

    # Stop current services
    log "Stopping current services..."
    docker-compose -f "$CURRENT_DEPLOYMENT/docker-compose.robot.yml" down || true

    # Check if previous deployment exists
    if [ -d "$PREVIOUS_DEPLOYMENT" ]; then
        log "Rolling back to previous deployment..."

        # Remove current deployment
        rm -rf "$CURRENT_DEPLOYMENT"

        # Restore previous deployment
        cp -r "$PREVIOUS_DEPLOYMENT" "$CURRENT_DEPLOYMENT"

        # Start previous services
        cd "$CURRENT_DEPLOYMENT"
        docker-compose -f docker-compose.robot.yml pull
        docker-compose -f docker-compose.robot.yml up -d

        # Verify services are running
        sleep 10
        if docker-compose -f docker-compose.robot.yml ps | grep -q "Up"; then
            log "Rollback successful - services are running"

            # Update previous deployment to current backup
            rm -rf "$PREVIOUS_DEPLOYMENT"
            mv "$BACKUP_DIR/$(ls -t $BACKUP_DIR | head -n1)" "$PREVIOUS_DEPLOYMENT"

            return 0
        else
            log "ERROR: Services not running after rollback"
            return 1
        fi
    else
        log "ERROR: No previous deployment found for rollback"
        return 1
    fi
}

# Function to emergency stop robot
emergency_stop() {
    log "Initiating emergency stop..."

    # Stop all robot services
    docker-compose -f "$CURRENT_DEPLOYMENT/docker-compose.robot.yml" down || true

    # Send emergency stop command to robot
    ssh robot@localhost "ros2 service call /emergency_stop std_msgs/Empty" || true

    # Cut power to motors (if hardware supports it)
    # This is hardware-specific and would need to be implemented

    log "Emergency stop initiated"
}

# Main execution
case "${1:-help}" in
    backup)
        backup_current
        ;;
    rollback)
        rollback
        ;;
    emergency)
        emergency_stop
        ;;
    *)
        echo "Usage: $0 {backup|rollback|emergency}"
        echo "  backup    - Create backup of current deployment"
        echo "  rollback  - Rollback to previous deployment"
        echo "  emergency - Emergency stop robot"
        exit 1
        ;;
esac

log "Script completed"
```
