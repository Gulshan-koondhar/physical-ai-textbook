# Introduction to Physical AI & Humanoid Robotics

Welcome to the comprehensive textbook on Physical AI & Humanoid Robotics: From Digital Intelligence to Embodied Humanoid Agents. This interactive textbook will guide you from zero to building a voice-controlled humanoid robot in one quarter.

## Overview

This textbook is structured across four comprehensive modules:

1. **Module 1** - ROS 2 fundamentals and humanoid robot modeling
2. **Module 2** - Physics simulation pipeline with Gazebo and Unity
3. **Module 3** - AI robot brain using NVIDIA Isaac platform
4. **Module 4** - Vision-Language-Action robotics and conversational interfaces

## Target Audience

This textbook is designed for:

- Generative AI engineers transitioning to robotics
- University/CS students in Physical AI, Embodied AI, or Robotics capstone courses
- Self-learners and hackathon participants aiming to build conversational humanoids

## Prerequisites

Before starting this textbook, you should have:

- Basic programming experience in Python
- Understanding of fundamental mathematics (linear algebra, calculus)
- Familiarity with Linux command line (Ubuntu 22.04 LTS)

## Learning Path

By the end of this textbook, you will have built a complete voice-controlled humanoid robot capable of understanding the command: "Find the red cup, pick it up, and bring it to me".
