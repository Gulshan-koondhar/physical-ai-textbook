URDF Repository

This appendix contains URDF (Unified Robot Description Format) and Xacro files for humanoid robots used throughout the textbook. These files define the physical structure, kinematics, and dynamics of robots.

URDF/Xacro Fundamentals​

URDF is an XML format for representing robot models. Xacro is an XML macro language that adds features like constants, expressions, and macros to URDF.

Basic URDF Structure​

<?xml version="1.0"?>
<robot name="humanoid_robot">
  <!-- Links define rigid bodies -->
  <link name="base_link">
    <visual>
      <geometry>
        <box size="0.2 0.2 0.2"/>
      </geometry>
    </visual>
    <collision>
      <geometry>
        <box size="0.2 0.2 0.2"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="1.0"/>
      <inertia ixx="0.1" ixy="0" ixz="0" iyy="0.1" iyz="0" izz="0.1"/>
    </inertial>
  </link>

  <!-- Joints connect links -->
  <joint name="joint1" type="revolute">
    <parent link="base_link"/>
    <child link="link1"/>
    <axis xyz="0 0 1"/>
    <limit lower="-1.57" upper="1.57" effort="100" velocity="1"/>
  </joint>
</robot>

Using URDF Files​

Loading in Gazebo​

# Spawn robot in Gazebo
ros2 run gazebo_ros spawn_entity.py -entity simple_humanoid -file path/to/robot.urdf -x 0 -y 0 -z 1

Visualizing in RViz​

# Launch robot state publisher
ros2 run robot_state_publisher robot_state_publisher --ros-args --param robot_description:=$(cat path/to/robot.urdf)

Testing with Joint State Publisher​

# Launch joint state publisher for visualization
ros2 run joint_state_publisher_gui joint_state_publisher_gui

Common URDF Issues and Solutions​

Inertia Issues​

  • Ensure all links have properly defined inertia tensors
  • Use the parallel axis theorem for complex shapes
  • Verify mass values are realistic

Joint Limits​

  • Set appropriate limits based on physical constraints
  • Consider actuator capabilities when setting effort and velocity limits
  • Use continuous joints for unlimited rotation (e.g., wheels)

Collision Meshes​

  • Use simplified collision meshes for performance
  • Ensure collision meshes are properly aligned with visual meshes
  • Check for self-collisions during motion

Xacro Best Practices​

Parameterization​

<xacro:property name="wheel_radius" value="0.1" />
<xacro:property name="wheel_width" value="0.05" />

Macros​

<xacro:macro name="simple_wheel" params="prefix parent xyz">
  <joint name="${prefix}_wheel_joint" type="continuous">
    <parent link="${parent}"/>
    <child link="${prefix}_wheel"/>
    <origin xyz="${xyz}" rpy="${-M_PI/2} 0 0"/>
    <axis xyz="0 0 1"/>
  </joint>

  <link name="${prefix}_wheel">
    <visual>
      <geometry>
        <cylinder radius="${wheel_radius}" length="${wheel_width}"/>
      </geometry>
    </visual>
  </link>
</xacro:macro>

File Organization​

  • Separate macros into include files
  • Use consistent naming conventions
  • Document custom xacro properties and macros

Advanced URDF Features​

Transmission Elements​

<transmission name="left_wheel_trans">
  <type>transmission_interface/SimpleTransmission</type>
  <joint name="left_wheel_joint">
    <hardwareInterface>hardware_interface/PositionJointInterface</hardwareInterface>
  </joint>
  <actuator name="left_wheel_motor">
    <mechanicalReduction>1</mechanicalReduction>
  </actuator>
</transmission>

Gazebo Plugins​

<gazebo reference="base_link">
  <material>Gazebo/Orange</material>
  <mu1>0.2</mu1>
  <mu2>0.2</mu2>
</gazebo>
