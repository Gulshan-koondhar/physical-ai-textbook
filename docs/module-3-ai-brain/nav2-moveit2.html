Nav2 and MoveIt 2 for Humanoid Robotics AI

Introduction

Navigation and manipulation are fundamental capabilities for humanoid robots, requiring sophisticated planning algorithms to operate in complex environments. Nav2 (Navigation 2) provides state-of-the-art navigation capabilities for mobile robots, while MoveIt 2 offers comprehensive motion planning for manipulator arms. For humanoid robots with both locomotion and manipulation capabilities, integrating both systems is essential for autonomous operation.

This chapter covers the configuration, setup, and integration of Nav2 and MoveIt 2 for humanoid robotics applications, focusing on AI-driven planning and execution.

Understanding Nav2 for Humanoid Locomotion

Nav2 Architecture Overview

Nav2 is built on ROS 2 and provides a flexible, behavior-based navigation system:

  1. Navigation Server: Main coordination node
  2. Planners: Global and local path planners
  3. Controllers: Trajectory controllers
  4. Recovery Behaviors: Fallback strategies
  5. Lifecycle Manager: State management

Nav2 Components for Humanoid Robots

For humanoid robots, Nav2 requires specific configurations:

  • Costmap Integration: For uneven terrain navigation
  • Footstep Planning: For bipedal locomotion
  • Humanoid Controllers: For walking gaits
  • Dynamic Obstacle Avoidance: For crowded environments

Understanding MoveIt 2 for Humanoid Manipulation

MoveIt 2 Architecture

MoveIt 2 provides motion planning for manipulator arms:

  1. MoveGroup Interface: High-level planning interface
  2. Planning Scene: World representation
  3. Motion Planners: Path planning algorithms
  4. Trajectory Execution: Controller interfaces
  5. Collision Detection: Safety checking

class HumanoidMoveItNode(Node):
    def __init__(self):
        super().__init__('humanoid_moveit_node')

        # Initialize MoveGroup action client
        self.move_group_client = ActionClient(
            self, MoveGroup, 'move_group')

        # Initialize joint state subscriber
        self.joint_state_sub = self.create_subscription(
            JointState, '/joint_states', self.joint_state_callback, 10)

        self.current_joint_state = JointState()

    def joint_state_callback(self, msg):
        """Update current joint state"""
        self.current_joint_state = msg

    def plan_to_pose(self, group_name, target_pose):
        """Plan motion to target pose"""
        goal_msg = MoveGroup.Goal()

        # Set planning group
        goal_msg.request.group_name = group_name

        # Set target pose
        goal_msg.request.workspace_parameters.header.frame_id = "base_link"

        # Create pose constraint
        pose_constraint = self.create_pose_constraint(
            target_pose, group_name)
        goal_msg.request.goal_constraints.append(pose_constraint)

        # Set planning options
        goal_msg.request.num_planning_attempts = 10
        goal_msg.request.allowed_planning_time = 5.0
        goal_msg.request.max_velocity_scaling_factor = 0.5
        goal_msg.request.max_acceleration_scaling_factor = 0.5

        return goal_msg

        """Create pose constraint for motion planning"""

Combining Nav2 and MoveIt 2

Create a unified planning system that coordinates navigation and manipulation:

# scripts/unified_planning_node.py
import rclpy
from rclpy.node import Node
from geometry_msgs.msg import PoseStamped, PointStamped
from moveit_msgs.msg import MoveItErrorCodes
from nav2_msgs.action import NavigateToPose
from moveit_msgs.action import MoveGroup
from rclpy.action import ActionClient
import json

class UnifiedPlanningNode(Node):
    def __init__(self):
        super().__init__('unified_planning_node')

        # Action clients
        self.nav_client = ActionClient(self, NavigateToPose, 'navigate_to_pose')
        self.moveit_client = ActionClient(self, MoveGroup, 'move_group')

        # Publishers and subscribers
        self.task_sub = self.create_subscription(
            String, '/planning_tasks', self.task_callback, 10)

        self.status_pub = self.create_publisher(
            String, '/planning_status', 10)

    def task_callback(self, msg):
        """Handle incoming planning tasks"""
        task = json.loads(msg.data)

        if task['type'] == 'navigation':
            self.execute_navigation_task(task)
        elif task['type'] == 'manipulation':
            self.execute_manipulation_task(task)
        elif task['type'] == 'combined':
            self.execute_combined_task(task)

    def execute_navigation_task(self, task):
        """Execute navigation-only task"""
        goal_pose = PoseStamped()
        goal_pose.pose.position.x = task['goal']['x']
        goal_pose.pose.position.y = task['goal']['y']
        goal_pose.pose.position.z = task['goal']['z']
        goal_pose.pose.orientation.w = 1.0

        goal_msg = NavigateToPose.Goal()
        goal_msg.pose = goal_pose

        self.nav_client.wait_for_server()
        future = self.nav_client.send_goal_async(goal_msg)
        future.add_done_callback(self.navigation_done_callback)

    def execute_manipulation_task(self, task):
        """Execute manipulation-only task"""
        goal_msg = MoveGroup.Goal()
        goal_msg.request.group_name = task['group']

        # Set target pose or joint positions
        if 'pose' in task:
            pose_constraint = self.create_pose_constraint(
                task['pose'], task['end_effector'])
            goal_msg.request.goal_constraints.append(pose_constraint)
        elif 'joints' in task:
            joint_constraint = self.create_joint_constraint(
                task['joints'], task['group'])
            goal_msg.request.goal_constraints.append(joint_constraint)

        self.moveit_client.wait_for_server()
        future = self.moveit_client.send_goal_async(goal_msg)
        future.add_done_callback(self.manipulation_done_callback)

    def execute_combined_task(self, task):
        """Execute combined navigation and manipulation task"""
        # First navigate to approach position
        nav_task = {
            'type': 'navigation',
            'goal': task['approach_pose']
        }

        # After navigation completes, execute manipulation
        self.execute_navigation_task(nav_task)
        # The manipulation will be triggered after navigation completes

    def navigation_done_callback(self, future):
        """Handle navigation completion"""
        goal_result = future.result()

        if goal_result.status == GoalStatus.STATUS_SUCCEEDED:
            self.get_logger().info('Navigation completed successfully')
            # If there's a manipulation task after navigation
            # self.execute_manipulation_task(self.pending_manipulation_task)
        else:
            self.get_logger().error('Navigation failed')

    def manipulation_done_callback(self, future):
        """Handle manipulation completion"""
        goal_result = future.result()

        if goal_result.status == GoalStatus.STATUS_SUCCEEDED:
            self.get_logger().info('Manipulation completed successfully')
        else:
            self.get_logger().error('Manipulation failed')

def main(args=None):
    rclpy.init(args=args)
    node = UnifiedPlanningNode()

    try:
        rclpy.spin(node)
    except KeyboardInterrupt:
        pass
    finally:
        node.destroy_node()
        rclpy.shutdown()

if __name__ == '__main__':
    main()

def generate_launch_description():
    # Launch configuration variables
    use_sim_time = LaunchConfiguration('use_sim_time', default='false')

    autostart = LaunchConfiguration('autostart', default='true')
    use_composition = LaunchConfiguration('use_composition', default='False')
    use_respawn = LaunchConfiguration('use_respawn', default='False')

    # Paths
    pkg_nav2_bringup = FindPackageShare('nav2_bringup')
    pkg_moveit_ros_benchmarks = FindPackageShare('moveit_ros_benchmarks')

    # Declare launch arguments
    declare_use_sim_time = DeclareLaunchArgument(
        'use_sim_time',
        default_value='false',
        description='Use simulation (Gazebo) clock if true'
    )

    declare_params_file = DeclareLaunchArgument(
        'params_file',
        default_value='config/nav2_params.yaml',
        description='Full path to the ROS2 parameters file to use for all launched nodes'
    )

    declare_autostart = DeclareLaunchArgument(
        'autostart',
        default_value='true',
        description='Automatically startup the nav2 stack'
    )

    declare_use_composition = DeclareLaunchArgument(
        'use_composition',
        default_value='False',
        description='Whether to use composed bringup'
    )

    declare_use_respawn = DeclareLaunchArgument(
        'use_respawn',
        default_value='False',
        description='Whether to respawn if a node crashes'
    )

    # Launch Nav2
    nav2_bringup_cmd = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            PathJoinSubstitution([
                FindPackageShare('nav2_bringup'),
                'launch',
                'navigation_launch.py'
            ])
        ),
        launch_arguments={
            'use_sim_time': use_sim_time,
            'params_file': params_file,
            'autostart': autostart,
            'use_composition': use_composition,
            'use_respawn': use_respawn
        }.items()
    )

    # Launch MoveIt 2
    moveit_cmd = IncludeLaunchDescription(
        PythonLaunchDescriptionSource(
            PathJoinSubstitution([
                FindPackageShare('humanoid_moveit_config'),
                'launch',
                'move_group.launch.py'
            ])
        ),
        launch_arguments={
            'use_sim_time': use_sim_time
        }.items()
    )

    # Unified planning node
    unified_planning_node = Node(
        package='humanoid_planning',
        executable='unified_planning_node',
        name='unified_planning_node',
        parameters=[{'use_sim_time': use_sim_time}],
        output='screen'
    )

    # Create launch description
    ld = LaunchDescription()

    # Add launch arguments
    ld.add_action(declare_use_sim_time)
    ld.add_action(declare_params_file)
    ld.add_action(declare_autostart)
    ld.add_action(declare_use_composition)
    ld.add_action(declare_use_respawn)

    # Add launch commands
    ld.add_action(nav2_bringup_cmd)
    ld.add_action(moveit_cmd)
    ld.add_action(unified_planning_node)

    return ld

Troubleshooting Common Issues

Navigation Issues

Issue: Robot Gets Stuck in Local Minima

Solutions:

  • Increase local costmap inflation radius
  • Use more sophisticated planners (SMP, STOMP)
  • Implement better recovery behaviors
  • Adjust controller parameters for smoother motion

Issue: Footstep Planning for Uneven Terrain

Solutions:

  • Use 3D costmaps for elevation awareness
  • Implement terrain classification
  • Add footstep optimization algorithms
  • Consider using specialized humanoid navigation packages

Manipulation Issues

Issue: Inverse Kinematics Failures

Solutions:

  • Increase joint limits tolerance
  • Use redundancy resolution
  • Implement multiple IK solvers as fallback
  • Add collision-aware IK constraints

Issue: Trajectory Execution Failures

Solutions:

  • Verify ros2_control configuration
  • Check joint state publisher
  • Validate controller configuration
  • Use trajectory monitoring and recovery

Best Practices for Humanoid Robotics

1. Hierarchical Planning

Implement hierarchical planning for complex humanoid tasks:

class HierarchicalPlanner:
    def __init__(self):
        self.task_planner = TaskPlanner()
        self.motion_planner = MotionPlanner()
        self.recovery_planner = RecoveryPlanner()

    def plan_task(self, task):
        """Plan at different levels of abstraction"""
        # High-level task planning
        high_level_plan = self.task_planner.plan(task)

        # Mid-level motion planning
        mid_level_plan = []
        for subtask in high_level_plan:
            motion_plan = self.motion_planner.plan(subtask)
            mid_level_plan.append(motion_plan)

        # Low-level execution
        return self.execute_plan(mid_level_plan)

2. Safety and Robustness

Implement comprehensive safety checks:

class SafetyManager:
    def __init__(self):
        self.balance_checker = BalanceChecker()
        self.collision_checker = CollisionChecker()
        self.emergency_stopper = EmergencyStopper()

    def check_safety(self, planned_motion):
        """Verify safety before execution"""
        if not self.balance_checker.is_stable(planned_motion):
            return False, "Balance violation"

        if self.collision_checker.will_collide(planned_motion):
            return False, "Collision detected"

        return True, "Safe to execute"

3. Adaptive Planning

Implement adaptive planning based on environment and robot state:

class AdaptivePlanner:
    def __init__(self):
        self.environment_analyzer = EnvironmentAnalyzer()
        self.robot_state_analyzer = RobotStateAnalyzer()
        self.planner_selector = PlannerSelector()

    def adapt_planning_strategy(self, current_state, environment):
        """Select appropriate planning strategy"""
        env_type = self.environment_analyzer.analyze(environment)
        robot_state = self.robot_state_analyzer.analyze(current_state)

        planner = self.planner_selector.select(env_type, robot_state)
        return planner
