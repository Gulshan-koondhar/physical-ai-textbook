URDF/Xacro Mastery

Introduction

The Unified Robot Description Format (URDF) is the standard XML format used in ROS for representing robots. For complex humanoid robots with 20+ degrees of freedom (DoF), URDF provides a structured way to define the robot's physical properties, kinematic chains, and visual representation. However, as robot complexity increases, raw URDF becomes unwieldy. This is where Xacro (XML Macros) comes to the rescue, allowing us to use variables, macros, and mathematical expressions to create clean, maintainable robot descriptions.

In this chapter, you'll learn to create sophisticated humanoid robot models using URDF and Xacro, with a focus on practical applications for 20+ DoF robots.

Understanding URDF Structure

Basic URDF Components

A URDF file describes a robot as a collection of rigid links connected by joints. Here's the basic structure:

<?xml version="1.0"?>
<robot name="humanoid_robot">
  <!-- Links define rigid bodies -->
  <link name="base_link">
    <visual>
      <geometry>
        <cylinder length="0.6" radius="0.2"/>
      </geometry>
    </visual>
    <collision>
      <geometry>
        <cylinder length="0.6" radius="0.2"/>
      </geometry>
    </collision>
    <inertial>
      <mass value="10"/>
      <inertia ixx="1.0" ixy="0.0" ixz="0.0" iyy="1.0" iyz="0.0" izz="1.0"/>
    </inertial>
  </link>

  <!-- Joints connect links -->
  <joint name="joint_name" type="revolute">
    <parent link="base_link"/>
    <child link="child_link"/>
    <origin xyz="0 0 0.3" rpy="0 0 0"/>
    <axis xyz="0 0 1"/>
    <limit lower="-3.14" upper="3.14" effort="100" velocity="1"/>
  </joint>
</robot>

Link Properties

Each link in a URDF must define three key properties:

  1. Visual: How the link appears in simulation and visualization
  2. Collision: How the link interacts with the physics engine
  3. Inertial: Physical properties for dynamics simulation

Joint Types

ROS supports several joint types:

  • revolute: Rotational joint with limited range
  • continuous: Rotational joint with unlimited range
  • prismatic: Linear sliding joint
  • fixed: No movement (welded connection)
  • floating: 6-DOF movement (rarely used)

Introducing Xacro

Xacro is a macro language that extends URDF with features like:

  • Variables and constants
  • Macros for reusable components
  • Mathematical expressions
  • Conditional blocks

Basic Xacro Syntax

<?xml version="1.0"?>
<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="humanoid_with_xacro">

  <!-- Define constants -->
  <xacro:property name="M_PI" value="3.1415926535897931" />
  <xacro:property name="base_radius" value="0.15" />
  <xacro:property name="base_length" value="0.2" />

  <!-- Define a macro for repeated elements -->
  <xacro:macro name="simple_cylinder_inertial" params="radius length mass *origin">
    <inertial>
      <mass value="${mass}" />
      <xacro:insert_block name="origin" />
      <inertia ixx="${0.0833333 * mass * (3 * radius * radius + length * length)}"
               iyy="${0.0833333 * mass * (3 * radius * radius + length * length)}"
               izz="${0.5 * mass * radius * radius}"
               ixy="0" ixz="0" iyz="0" />
    </inertial>
  </xacro:macro>

  <link name="base_link">
    <visual>
      <geometry>
        <cylinder radius="${base_radius}" length="${base_length}"/>
      </geometry>
    </visual>
    <collision>
      <geometry>
        <cylinder radius="${base_radius}" length="${base_length}"/>
      </geometry>
    </collision>
    <xacro:simple_cylinder_inertial radius="${base_radius}" length="${base_length}" mass="10">
      <origin xyz="0 0 0" rpy="0 0 0"/>
    </xacro:simple_cylinder_inertial>
  </link>

</robot>

Building a Humanoid Robot Model

Let's create a simplified humanoid model focusing on the key principles. For a complete 22-DoF humanoid, we'll need to model:

  • Torso with 6 DoF (waist rotation, chest movement)
  • 2 Arms with 7 DoF each (shoulder: 3 DoF, elbow: 1 DoF, wrist: 2 DoF, hand: 1 DoF)
  • 2 Legs with 6 DoF each (hip: 3 DoF, knee: 1 DoF, ankle: 2 DoF)

Complete Humanoid Xacro Example

<robot xmlns:xacro="http://www.ros.org/wiki/xacro" name="simple_humanoid">

  <xacro:property name="M_PI" value="3.1415926535897931" />

    <color rgba="0.0 0.0 0.0 1.0"/>
  </material>
  <material name="blue">
    <color rgba="0.0 0.0 0.8 1.0"/>
  </material>
  <material name="green">
    <color rgba="0.0 0.8 0.0 1.0"/>
  </material>
  <material name="grey">
    <color rgba="0.2 0.2 0.2 1.0"/>
  </material>
  <material name="orange">
    <color rgba="1.0 0.423529411765 0.0392156862745 1.0"/>
  </material>
  <material name="brown">
    <color rgba="0.870588235294 0.811764705882 0.764705882353 1.0"/>
  </material>
  <material name="red">
    <color rgba="0.8 0.0 0.0 1.0"/>
  </material>
  <material name="white">
    <color rgba="1.0 1.0 1.0 1.0"/>
  </material>

  <!-- Inertial macros -->
  <xacro:macro name="cylinder_inertial" params="mass length radius *origin">
    <inertial>
      <mass value="${mass}" />
      <xacro:insert_block name="origin" />
      <inertia ixx="${0.0833333 * mass * (3 * radius * radius + length * length)}"
               iyy="${0.0833333 * mass * (3 * radius * radius + length * length)}"
               izz="${0.5 * mass * radius * radius}"
               ixy="0" ixz="0" iyz="0" />
    </inertial>
  </xacro:macro>

  <xacro:macro name="box_inertial" params="mass x y z *origin">
    <inertial>
      <mass value="${mass}" />
      <xacro:insert_block name="origin" />
      <inertia ixx="${0.0833333 * mass * (y*y + z*z)}"
               iyy="${0.0833333 * mass * (x*x + z*z)}"
               izz="${0.5 * mass * (x*x + y*y)}"
               ixy="0" ixz="0" iyz="0" />
    </inertial>
  </xacro:macro>

  <xacro:macro name="sphere_inertial" params="mass radius *origin">
    <inertial>
      <mass value="${mass}" />
      <xacro:insert_block name="origin" />
      <inertia ixx="${0.4 * mass * radius * radius}"
               iyy="${0.4 * mass * radius * radius}"
               izz="${0.4 * mass * radius * radius}"
               ixy="0" ixz="0" iyz="0" />
    </inertial>
  </xacro:macro>

  <!-- Base link -->
  <link name="base_link">
    <visual>
      <geometry>
        <box size="0.1 0.1 0.1"/>
      </geometry>
      <material name="blue"/>
    </visual>
    <collision>
      <geometry>
        <box size="0.1 0.1 0.1"/>
      </geometry>
    </collision>
    <xacro:box_inertial mass="1" x="0.1" y="0.1" z="0.1">
      <origin xyz="0 0 0"/>
    </xacro:box_inertial>
  </link>

  <!-- Torso -->
  <joint name="torso_joint" type="fixed">
    <parent link="base_link"/>
    <child link="torso_link"/>
    <origin xyz="0 0 0.05" rpy="0 0 0"/>
  </joint>

  <link name="torso_link">
    <visual>
      <geometry>
        <box size="0.2 0.15 0.4"/>
      </geometry>
      <material name="white"/>
    </visual>
    <collision>
      <geometry>
        <box size="0.2 0.15 0.4"/>
      </geometry>
    </collision>
    <xacro:box_inertial mass="5" x="0.2" y="0.15" z="0.4">
      <origin xyz="0 0 0"/>
    </xacro:box_inertial>
  </link>

  <!-- Head -->
  <joint name="neck_joint" type="revolute">
    <parent link="torso_link"/>
    <child link="head_link"/>
    <origin xyz="0 0 0.25" rpy="0 0 0"/>
    <axis xyz="0 1 0"/>
    <limit lower="${-M_PI/4}" upper="${M_PI/4}" effort="10" velocity="1"/>
  </joint>

  <link name="head_link">
    <visual>
      <geometry>
        <sphere radius="0.1"/>
      </geometry>
      <material name="white"/>
    </visual>

      <geometry>
        <sphere radius="0.1"/>
      </geometry>
    </collision>
    <xacro:sphere_inertial mass="1" radius="0.1">

    </xacro:sphere_inertial>
  </link>

  <!-- Left Arm -->
  <joint name="left_shoulder_yaw" type="revolute">
    <parent link="torso_link"/>

  </joint>

  <link name="left_upper_arm">
    <visual>
      <geometry>
        <cylinder radius="0.05" length="0.3"/>
      </geometry>
      <origin xyz="0 0 0.15" rpy="${M_PI/2} 0 0"/>
      <material name="orange"/>
    </visual>
    <collision>
      <geometry>
        <cylinder radius="0.05" length="0.3"/>
      </geometry>
      <origin xyz="0 0 0.15" rpy="${M_PI/2} 0 0"/>
    </collision>
    <xacro:cylinder_inertial mass="1" length="0.3" radius="0.05">
      <origin xyz="0 0 0.15" rpy="${M_PI/2} 0 0"/>
    </xacro:cylinder_inertial>
  </link>

  <joint name="left_elbow" type="revolute">
    <parent link="left_upper_arm"/>
    <child link="left_lower_arm"/>
    <origin xyz="0 0 0.3" rpy="0 0 0"/>

    <limit lower="0" upper="${M_PI}" effort="10" velocity="1"/>

  <link name="left_lower_arm">
    <visual>
      <geometry>

Advanced Xacro Techniques

Parameterized Macros

Xacro macros can accept parameters to create reusable components:

<xacro:macro name="simple_arm" params="side parent_link x_pos y_pos z_pos">
  <!-- Shoulder joint -->
  <joint name="${side}_shoulder_yaw" type="revolute">
    <parent link="${parent_link}"/>
    <child link="${side}_upper_arm"/>
    <origin xyz="${x_pos} ${y_pos} ${z_pos}" rpy="0 0 0"/>
    <axis xyz="0 0 1"/>
    <limit lower="${-M_PI/2}" upper="${M_PI/2}" effort="10" velocity="1"/>
  </joint>

  <link name="${side}_upper_arm">
    <visual>
      <geometry>
        <cylinder radius="0.05" length="0.3"/>
      </geometry>
      <origin xyz="0 0 0.15" rpy="${M_PI/2} 0 0"/>
      <material name="orange"/>
    </visual>
    <collision>
      <geometry>
        <cylinder radius="0.05" length="0.3"/>
      </geometry>
      <origin xyz="0 0 0.15" rpy="${M_PI/2} 0 0"/>
    </collision>
    <xacro:cylinder_inertial mass="1" length="0.3" radius="0.05">
      <origin xyz="0 0 0.15" rpy="${M_PI/2} 0 0"/>
    </xacro:cylinder_inertial>
  </link>

  <!-- Elbow joint -->
  <joint name="${side}_elbow" type="revolute">
    <parent link="${side}_upper_arm"/>
    <child link="${side}_lower_arm"/>
    <origin xyz="0 0 0.3" rpy="0 0 0"/>
    <axis xyz="0 1 0"/>
    <limit lower="0" upper="${M_PI}" effort="10" velocity="1"/>
  </joint>

  <link name="${side}_lower_arm">
    <visual>
      <geometry>
        <cylinder radius="0.04" length="0.25"/>
      </geometry>
      <origin xyz="0 0 0.125" rpy="${M_PI/2} 0 0"/>
      <material name="orange"/>
    </visual>
    <collision>
      <geometry>
        <cylinder radius="0.04" length="0.25"/>
      </geometry>
      <origin xyz="0 0 0.125" rpy="${M_PI/2} 0 0"/>
    </collision>
    <xacro:cylinder_inertial mass="0.8" length="0.25" radius="0.04">
      <origin xyz="0 0 0.125" rpy="${M_PI/2} 0 0"/>
    </xacro:cylinder_inertial>
  </link>
</xacro:macro>

<!-- Use the macro to create both arms -->
<xacro:simple_arm side="left" parent_link="torso_link" x_pos="0.15" y_pos="0" z_pos="0.1"/>
<xacro:simple_arm side="right" parent_link="torso_link" x_pos="-0.15" y_pos="0" z_pos="0.1"/>

Mathematical Expressions

Xacro supports mathematical expressions using Python's eval function:

<xacro:property name="arm_length" value="0.3" />
<xacro:property name="elbow_offset" value="${arm_length / 2}" />

<!-- This will evaluate to 0.15 -->
<origin xyz="0 0 ${elbow_offset}" rpy="0 0 0"/>

Conditional Blocks

Use xacro if statements to conditionally include content:

<xacro:property name="include_gripper" value="true" />

<xacro:if value="${include_gripper}">
  <joint name="gripper_joint" type="prismatic">
    <parent link="left_lower_arm"/>
    <child link="gripper"/>
    <origin xyz="0 0 0.25" rpy="0 0 0"/>
    <axis xyz="1 0 0"/>
    <limit lower="0" upper="0.05" effort="5" velocity="0.5"/>
  </joint>
</xacro:if>

Best Practices for Humanoid URDF/Xacro

1. Organize by Functional Groups

Structure your Xacro file to group related components:

<!-- Header and constants -->
<!-- Materials -->
<!-- Inertial macros -->
<!-- Base and torso -->
<!-- Left arm chain -->
<!-- Right arm chain -->
<!-- Left leg chain -->
<!-- Right leg chain -->
<!-- Sensors -->
<!-- Transmission definitions -->

2. Use Descriptive Names

Follow a consistent naming convention:

  • Links: body_part_link (e.g., left_upper_arm_link)
  • Joints: body_part_joint (e.g., left_shoulder_pitch_joint)
  • Avoid generic names like link1, joint2

3. Validate Your URDF

Use ROS tools to check your URDF:

# Check for XML syntax errors
xacro my_robot.urdf.xacro

# Check for kinematic loops and other issues
check_urdf my_robot.urdf

4. Consider Computational Complexity

For complex humanoid robots:

  • Use simplified collision geometries where possible
  • Reduce the number of small, detailed meshes
  • Balance visual fidelity with simulation performance

Working with URDF in ROS 2

Launching with Robot State Publisher

To visualize your robot in RViz2, use the robot_state_publisher:

<launch>
  <!-- Load the URDF into the parameter server -->
  <node pkg="robot_state_publisher" exec="robot_state_publisher" name="robot_state_publisher">
    <param name="robot_description" value="$(var robot_description)"/>
  </node>
</launch>

TF Trees

URDF automatically generates a transform tree (TF) based on your joint definitions. You can visualize this in RViz2 or with:

ros2 run tf2_tools view_frames
