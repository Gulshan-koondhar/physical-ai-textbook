# Hardware Guide

This chapter provides detailed information about the hardware requirements and setup for implementing the Physical AI & Humanoid Robotics system. The recommended hardware configuration balances performance, cost, and accessibility for learners.

## System Requirements

### Development Workstation
- **GPU**: NVIDIA RTX 3080 or better (RTX 4080/4090 recommended)
- **CPU**: 16+ cores, high clock speed (AMD Ryzen 9 or Intel i9)
- **RAM**: 64GB DDR4/DDR5
- **Storage**: 2TB+ NVMe SSD for models and datasets
- **OS**: Ubuntu 22.04 LTS

### Embedded Platform
- **Jetson Orin**: NVIDIA Jetson AGX Orin Developer Kit
- **Power**: 60W AC adapter (for sustained performance)
- **Storage**: 64GB+ eMMC or microSD card
- **Connectivity**: WiFi 6E, Ethernet, Bluetooth 5.0

## Recommended Humanoid Platforms

### Unitree G1
- 32+ degrees of freedom
- Integrated control system
- ROS 2 support
- Good documentation and community

### Unitree Go2
- 18+ degrees of freedom
- Quadruped platform (good for learning locomotion)
- ROS 2 support
- More affordable than G1

### Custom Build Options
- Consider using Dynamixel servos for custom designs
- CAD files for 3D printing available in Appendix B
- Electronics: Raspberry Pi 4 or NVIDIA Jetson Nano for perception

## Setup Instructions

### RTX Workstation Setup
1. Install Ubuntu 22.04 LTS
2. Install NVIDIA drivers (535+ recommended)
3. Install CUDA 12.x and cuDNN
4. Install Isaac Sim for simulation
5. Set up development environment

### Jetson Orin Setup
1. Flash JetPack 5.1+ on the developer kit
2. Install ROS 2 Humble
3. Install TensorRT for model optimization
4. Configure power mode for sustained performance
5. Set up cross-compilation environment

## Troubleshooting Common Issues

### GPU Memory Issues
- Monitor GPU memory usage: `nvidia-smi`
- Reduce batch sizes in AI models if needed
- Consider model quantization for deployment

### ROS 2 Network Configuration
- Set up proper ROS_DOMAIN_ID for multi-robot systems
- Configure RMW middleware for performance
- Use DDS implementations appropriately

## Cost Considerations

The total hardware cost ranges from $10,000 to $50,000 depending on the humanoid platform chosen:

- **Budget Option**: Custom build with Dynamixel servos (~$8,000)
- **Mid-Range**: Unitree Go2 + RTX 4080 workstation (~$20,000)
- **Premium Option**: Unitree G1 + RTX 4090 workstation (~$40,000)

## Alternative Platforms

### Simulation-Only Development
- Use Isaac Sim and Gazebo for complete development
- Deploy to cloud robotics platforms
- Access to high-end GPUs via cloud services

### Educational Discounts
- Check NVIDIA's educational programs for hardware discounts
- Academic institutions may have robotics labs with available hardware
- Consider collaborative projects to share costs

## Maintenance and Upgrades

### Regular Maintenance
- Clean fans and thermal paste on GPUs
- Update firmware on humanoid platforms
- Backup configurations and custom software

### Future-Proofing
- Choose hardware with upgrade paths
- Consider next-generation GPU releases
- Plan for AI model size increases

## Summary

This hardware guide provides the foundation for implementing the Physical AI & Humanoid Robotics system. The recommended configurations balance performance requirements with accessibility for different learning environments.
