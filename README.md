# Physical AI & Humanoid Robotics Textbook

This repository contains an interactive textbook for learning Physical AI & Humanoid Robotics: From Digital Intelligence to Embodied Humanoid Agents.

## Overview

This comprehensive textbook guides learners from zero to building a voice-controlled humanoid robot in one quarter. The curriculum is structured across four modules:

1. **Module 1** - ROS 2 fundamentals and humanoid robot modeling
2. **Module 2** - Physics simulation pipeline with Gazebo and Unity
3. **Module 3** - AI robot brain using NVIDIA Isaac platform
4. **Module 4** - Vision-Language-Action robotics and conversational interfaces

The final capstone project enables a complete voice-command demonstration: "Find the red cup, pick it up, and bring it to me".

## Getting Started

1. Install dependencies:
   ```bash
   npm install
   ```

2. Start the development server:
   ```bash
   npm start
   ```

3. Open your browser to `http://localhost:3000` to view the textbook.

## Project Structure

- `docs/` - Textbook content in MDX format
- `src/` - Custom Docusaurus components and styling
- `static/` - Static assets like images, models, and launch files
- `.github/workflows/` - GitHub Actions for deployment
